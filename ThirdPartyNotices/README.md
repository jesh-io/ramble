# Third-party notices

This directory contains license/notice texts from the resolved Swift dependencies.
Root dependencies are pinned in `Package.resolved`; the iPhone dependency graph
comes from `RamblePhone/project.yml`. All are MIT or Apache-2.0 licensed; the
Swift projects may include the Swift runtime-library exception. Refer to the
individual texts for exact terms, authors and additional notices.

macOS: OpenMultitouchSupport (optional gestures), swift-async-algorithms and
swift-collections. iPhone additionally resolves mlx-swift, mlx-swift-lm,
swift-huggingface, swift-transformers, swift-jinja, swift-argument-parser,
swift-syntax, swift-numerics, swift-crypto, swift-asn1, EventSource and yyjson.
Vendored MLX, mlx-c, metal-cpp and fmt notices are included too.

These notices describe code dependencies, not downloaded model weights. Model
downloads have their own licenses and are not included in the release archives.
