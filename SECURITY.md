# Security

Report vulnerabilities privately to **git@jeshu.run**. Include reproduction
steps with synthetic data, the version, and impact. Do not include credentials,
recordings, transcripts, or personal configuration. Avoid opening a public issue
until we have coordinated a fix. The latest published release is supported.

Ramble uses Microphone and optional Accessibility permissions. Remote providers
receive selected audio/text; use on-device engines for private work. Treat
configuration and local history as sensitive even when credentials live in Keychain.
